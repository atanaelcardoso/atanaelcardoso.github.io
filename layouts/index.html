CineScope

Catálogo web em português para descobrir filmes populares, pesquisar títulos e organizar listas de favoritos e filmes assistidos.

O que implementei

  • Catálogo de filmes com dados do TMDB, pesquisa por título e navegação paginada.
  • Listas de favoritos e filmes assistidos salvas no navegador, além de integrações locais com S3 e SNS usando LocalStack.

Competências aplicadas

Python + Django
Aplicação web para organizar as páginas do catálogo e integrar os dados dos filmes.
TMDB API
Consumo de uma API externa para apresentar títulos, pôsteres e sinopses.
PostgreSQL + Docker Compose
Banco de dados e serviços configurados para execução local reproduzível.
AWS + LocalStack
Prática com boto3, S3, SNS e uma função Lambda em ambiente local.
pytest
Testes automatizados com pytest e pytest-django.

Discord Clone

Desafio Full Stack

Desafio técnico com um cenário de organização de tarefas domésticas: quando tarefas, responsáveis e andamento ficam dispersos, torna-se mais difícil acompanhar o que ainda precisa ser feito.

O que implementei

  • Cadastro e login, criação de tarefas e visualização da lista com filtros por status.
  • Interface web React que consome uma API própria; usuários e tarefas são relacionados no banco de dados.

Por que essa arquitetura

React + TypeScript
A interface web é composta por telas e componentes reutilizáveis; os tipos ajudam a manter consistentes os dados das tarefas.
API Node.js + Express
Centraliza autenticação e operações de tarefas e mantém a interface separada das regras do servidor.
Camada de domínio
Separar casos de uso e acesso a dados da camada HTTP deixa as regras mais organizadas e facilita sua evolução.
SQLite + Prisma
Atende ao escopo de um desafio local sem exigir um servidor de banco; o modelo relacional representa a relação entre usuários e tarefas.
