Discord Clone

Projeto de estudo inspirado em plataformas de comunidades. O desafio é organizar conversas por servidores e canais, relacionando participantes, cargos e mensagens.

O que implementei

  • Operações de criação, consulta e atualização para usuários, servidores, canais e cargos, além do ciclo de mensagens.
  • Modelo relacional para representar associações entre membros, servidores, cargos, canais e mensagens.

Por que essa arquitetura

React + TypeScript
Componentes reutilizáveis para a interface e tipos para explicitar os formatos de dados trocados com a API.
Node.js + Express
API separada do cliente para organizar rotas e regras do servidor sem acoplar a aplicação à interface.
MySQL + Prisma
O modelo relacional representa as entidades conectadas do domínio; o ORM centraliza o schema e o acesso aos dados.
Docker Compose
Facilita subir a aplicação e seus serviços de desenvolvimento com uma configuração reproduzível.

Desafio Full Stack

Desafio técnico com um cenário de organização de tarefas domésticas: quando tarefas, responsáveis e andamento ficam dispersos, torna-se mais difícil acompanhar o que ainda precisa ser feito.

O que implementei

  • Cadastro e login, criação de tarefas e visualização da lista com filtros por status.
  • Interface web React que consome uma API própria; usuários e tarefas são relacionados no banco de dados.

Por que essa arquitetura

React + TypeScript
A interface web é composta por telas e componentes reutilizáveis; os tipos ajudam a manter consistentes os dados das tarefas.
API Node.js + Express
Centraliza autenticação e operações de tarefas e mantém a interface separada das regras do servidor.
Camada de domínio
Separar casos de uso e acesso a dados da camada HTTP deixa as regras mais organizadas e facilita sua evolução.
SQLite + Prisma
Atende ao escopo de um desafio local sem exigir um servidor de banco; o modelo relacional representa a relação entre usuários e tarefas.
